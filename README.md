## Ejecución

```
python ejercicio1.py
python ejercicio2.py
python ejercicio3.py
python ejercicio4.py
```

- `ejercicio1.py`: ordena una lista de diccionarios según una key usando `sorted` con `lambda`.
- `ejercicio2.py`: calcula la potencia n-ésima de cada elemento de una lista usando `map` con `lambda`.
- `ejercicio3.py`: calcula la transpuesta de una matriz usando `map` con `lambda`.
- `ejercicio4.py`: elimina de una lista los elementos indicados en otra usando `filter` con `lambda`.

Cada programa muestra primero el ejemplo del enunciado y luego permite ingresar casos propios. Para salir se presiona Enter sin escribir nada.
